### **Enunciado**

**Criterios de evaluación:**

Desarrollo de la consigna
Diseño responsive y estilo de la página
Consistencia y prolijidad en el código HTML y CSS
Correcto uso de Git: ramas, commits descriptivos, merge, y publicación en GitHub Pages
Entrega en tiempo y forma


**Consigna:**

Desarrollar una página web utilizando únicamente HTML y CSS que contenga una tarjeta de noticia destacada (news card).
La página debe estar centrada en pantalla y la tarjeta debe verse correctamente tanto en mobile como en desktop (responsive).



**Requerimientos HTML/CSS:**

Imagen de portada de la noticia (puede ser un placeholder o imagen libre).
Categoría de la noticia mostrada como badge/etiqueta (ej: "Tecnología", "Deportes").
Título principal de la noticia.
Bajada o copete (texto breve de 2 a 3 líneas).
Nombre del autor y fecha de publicación.
Un botón o link de "Leer más" estilizado.
Uso de Flexbox para el layout interno de la tarjeta.
Al menos una media query para adaptar el diseño a pantallas pequeñas (max-width: 600px).


**Requerimientos Git y GitHub Pages:**

Crear un repositorio en GitHub con el nombre indicado.
Inicializar el repositorio localmente con git init y hacer el primer commit en la rama main.
Crear una rama de desarrollo: git checkout -b desarrollo.
Realizar los cambios y commits en la rama desarrollo con mensajes descriptivos.
Hacer merge de desarrollo a main: git checkout main → git merge desarrollo.
Activar GitHub Pages desde la rama main y entregar la URL pública del sitio.
Entregar también la URL del repositorio de GitHub.
